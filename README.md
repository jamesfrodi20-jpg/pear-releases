# Pear Local Agent downloads

Installers for **Pear Local Agent**, which connects your [Pear](https://pearai-dev.vercel.app) account to Roblox Studio on your computer.

**[Download the latest version](https://github.com/jamesfrodi20-jpg/pear-releases/releases/latest)** · [Setup guide](https://pearai-dev.vercel.app/local-agent.html)

- Windows 10/11: `PearLocalAgent-Windows.exe`
- macOS (Apple silicon and Intel): `PearLocalAgent-macOS.dmg`
- Linux: `PearLocalAgent-Linux.AppImage` or `.deb` (Roblox Studio doesn't run on Linux yet)

This repository only hosts release files. Checksums are attached to each release as `SHA256SUMS.txt`.
